## 任务：修复 MuJoCo + vuer VR 演示（demo_vuer_vr.py）

### 问题 1：机器人各部件角度不对 / 无法站立

**结论：坐标系变换本身是正确的，根因是另外两点。**

排查过程与证据：
1. 逐一验证 30 个 visual mesh geom 的世界位姿，左右完美镜像（L Y>0 / R Y<0），
   高度图连贯（脚 z≈-0.08、躯干 0.9–1.5、手腕前伸 X≈+0.3）→ 变换无误。
2. MuJoCo 为 Z-up，three.js/vuer 为 Y-up，换算 `(x,y,z) -> (x,z,-y)`，
   即 `M = [[1,0,0],[0,0,1],[0,-1,0]]`。旋转用相似变换 `R' = M·R·Mᵀ`；
   因 M 是纯旋转（det=+1），与 `M·R` 数学等价。
3. **关键点**：elf3.xml 的 STL 是局部坐标网格，mesh 对齐变换在编译时被
   MuJoCo 烘焙进 geom 的相对位姿。因此渲染**必须用 `data.geom_xpos` /
   `data.geom_xmat`（geom 世界位姿）**，不能用 body 位姿。
4. 万向节锁死：用 4x4 矩阵属性（列主序）+ `matrixAutoUpdate=false`，
   替代 rotation 欧拉角。
5. 落地：脚 capsule 中心 z=0.0525、半径 0.015 → 底面 z=0.0375，地面 z=0，
   初始悬空 3.75cm。脚本把基座下移 FOOT_GAP 使双脚落地。
6. 站立：双足无平衡控制器，自由基座必在 1–3s 内倾倒。**必须钉基座**
   （`data.qpos[:7] = QPOS0[:7]`，`data.qvel[:6] = 0`）+ 关节 PD。
   KP=150 / KD=5 时关节误差仅 0.0245 rad（1.4°）。

### vuer 0.1.6 关键 API 事实（实测确认）

- **传输协议是 msgpack**（`packb`/`unpackb`），**不是 JSON**。
  用 JSON 发送事件会导致服务端 `TypeError: a bytes-like object is required`。
- **本地服务器在根路径 `/` 直接托管 WebXR 客户端**（`socket_index` 在非
  upgrade 请求时返回 `client_build/index.html`），并在同一端口提供 WebSocket。
  实测 `http://127.0.0.1:PORT/` 返回 `200 text/html`，8/8 静态资源可访问。
- 因此有两套入口：
  - 本地托管：`http://<IP>:8012`（推荐，无需外网）
  - 远程客户端：`https://vuer.ai?ws=ws://<IP>:8012`（`domain` 默认 `https://vuer.ai`）
- `Server.start()` 内部会 `event_loop.run_forever()`（**阻塞**）；
  `Vuer.run()` 只是 `start()` 的已弃用别名。`@app.spawn(start=True)`
  在**装饰阶段**就调用 `start()` → 脚本无需再写 `app.run()`。
- spawn handler 在 `_run_session` 定义**之前**被调用会 `NameError`，
  因此被调函数必须定义在 `@app.spawn` 装饰的函数之前。
- 手柄事件回调签名：`async def f(client_event, session_proxy)`
  （`vuer/server.py:938` → `fn_factory(client_event, session_proxy)`），
  用 `app.add_handler("CONTROLLER_MOVE", f)` 做**全局**注册。
  `VuerSession` 上**没有** `add_handler`。
- `CONTROLLER_MOVE` 的 `value.{left,right}` 是 16 元素列主序位姿矩阵，
  `.{left,right}State` 含 `trigger/squeeze/aButton/bButton/triggerValue/
  squeezeValue/thumbstickValue[2]`。
- `HapticActuatorPulse(left={"strength":..,"duration":..}, right=...)`。
- `Text` 的内容从 **children** 读取（`Text("字符串")`），不是 `text=` 属性。
